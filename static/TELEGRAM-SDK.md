telegram-web-app.js is an unmodified copy of Telegram's official Mini App SDK,
downloaded from https://telegram.org/js/telegram-web-app.js on 2026-10-24.
It is served locally so a blocked or failed external telegram.org script request
does not prevent the Telegram WebView from parsing its signed launch data.
Authoritative integration documentation: https://core.telegram.org/bots/webapps
